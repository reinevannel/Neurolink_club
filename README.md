# 🌌 Neurolink_club

A calm digital space designed for autistic and neurodivergent people, where every interaction stays predictable, gentle, and easy to understand.
---

This project was created as part of the **Codecademy Front-End Developer program**.


## 🌿 Concept

Neurolink_club is built around one idea:  
**clarity before complexity, calm before features.**

The app offers quiet rooms, soft interactions, and a social‑energy indicator that adapts the interface to the user’s current state.  
No noise. No pressure. Just a place to breathe and connect at your own rhythm.

---

## ✨ Core Principles

- 🧠 **Predictable UX** — no surprises, no sudden animations.  
- 🌙 **Calm UI** — soft colors, stable typography, gentle transitions.  
- 🤝 **Human‑first design** — direct sentences, respectful pacing.  
- 🔍 **Accessibility** — built for neurodivergent profiles, including autistic and formerly Asperger‑identified users.  
- 🌱 **Emotional safety** — rooms filtered by “social battery” to avoid overload.

## 🔧 Open the Project

Open **PowerShell inside this folder**.  
Make sure it is **not** the “Welcome to Node.js” window.

```powershell
npm.cmd install
npm.cmd run dev


Then open:

[http://127.0.0.1:8080](http://127.0.0.1:8080)

Keep PowerShell open.  
To stop the server: Ctrl + C

If port 8080 is already in use:

```powershell
npx vite --host 127.0.0.1 --port 8081
```

The link becomes:

[http://127.0.0.1:8081](http://127.0.0.1:8081)

If installation freezes, move the project outside OneDrive.  
Example: `C:\aethernest`

## 💬 Why Neurolink_club

Some people need digital spaces that don’t rush them.  
Neurolink_club explores what happens when design respects sensitivity, rhythm, and cognitive clarity.  
A small experiment in building interfaces that feel like a soft place to land.
